# Система оформления заказа обуви

## Описание

Приложение для автоматизации процесса выбора и заказа обуви клиентами компании. Система позволяет просматривать каталог товаров с актуальным наличием, рассчитывать цены со скидками, оформлять заказы и управлять ими (для менеджеров и администраторов).

**Основные функции:**
*   Просмотр каталога моделей обуви с изображениями и характеристиками.
*   Фильтрация по категориям, поиск по названию/описанию и сортировка по цене.
*   Расчет стоимости товара с учетом скидки (25% на товары без заказов в прошлом месяце).
*   Оформление заказа авторизованными пользователями (выбор размера и количества).
*   Управление заказами: просмотр списка, добавление/удаление позиций, редактирование дат (для ролей Администратор и Менеджер).
*   Интеграция с СУБД (нормализация до 3НФ, ссылочная целостность).
